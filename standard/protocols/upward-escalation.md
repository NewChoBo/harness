# Upward Review / Decision Requests

Escalate only when higher-level judgment can materially change scope, priority, authority, architecture, release sequencing, destructive migration, or risk handling.

A decision request contains:

- `DECISION / QUESTION`;
- `WHY NOW`;
- material options and trade-offs;
- `RECOMMENDED DEFAULT` when evidence supports one;
- `IF DEFERRED` impact;
- exact owner/evidence references when available.

Do not escalate routine reversible implementation details that the current role can resolve under existing authority. If no higher-level input is needed, state `No upward decision required`.
