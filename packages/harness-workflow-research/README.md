## Harness workflow: research

This package is the shared starting workflow for research/exploration tasks.

Use this when you need:
- explicit uncertainty tracking,
- counterexample checks before adoption,
- explicit distinction between exploratory and candidate workstreams.

What this package provides:
- `preset.yaml`: baseline workflow preset for investigation tasks
- `research-overlay.md`: copy-editable overlay defaults

Usage pattern:
- keep long-form evidence in repository-owned notes,
- reference this preset as a starter, then
- add project-specific methods and constraints through overlays.
